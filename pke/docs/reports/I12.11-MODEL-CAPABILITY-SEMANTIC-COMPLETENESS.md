## Why I12.6 was insufficient

I12.6 ran before:

- Event downstream preservation (I12.7 / I12.7.1)
- Safe partial Event handling
- Structured proposal execution readiness (I12.10)

Therefore I12.6 could not answer whether a model produces **enough correct structured semantics for useful safe execution**. I12.11 is a new evaluation under a better-instrumented Engine, not a retroactive fix of I12.6.

## Interpretation

1. **No available candidate materially improves useful semantic completeness** under frozen thresholds.
2. `deepseek-reasoner` is **REJECTED_SAFETY** for mass unsupported object/subject invention (precision collapse).
3. Completeness is **MIXED** model-dependent: reasoner invents/omits differently, but **MP1 subject gap is shared** → not fixed by switching to the only other callable DeepSeek model.
4. SemanticProposal expressiveness is **demonstrated** (MP2/MP3/MP5). Do not conclude proposal change from omission alone.
5. Safety of the Engine path remains intact (POST_S4=0; no false Event canonicalization; no Event post-loss). Reliability for Engine v1 useful capture remains **insufficient**.

Regression (harness + Engine): **3271 passed**, 0 failed, 8 live deselected.
