| Field | Value |

| **PARENT** | — *(top-level EVENT_TYPE; `seeds.py`)* |
| **INTENDED_SEMANTICS** | Intention / planned-event category — **not** a generic occurrence bucket |
| **EXAMPLES** | *(none defined in CORE seeds or aliases)* |

Sources: `src/pke/ontology/seeds.py:149`, `docs/reports/I11-GENERALIZATION-BASELINE.md` (actions & events table).

### Classification (§8)

```text
INTENTION_OR_PLANNED_EVENT_CONCEPT
```

Not `GENERIC_EVENT_FALLBACK` — label and I11 table describe *Intenção*, not “any event”.

### Fallback verdict (§9)

| Utterance class | `event.intent` safe? |
|-----------------|----------------------|
| “pesei a caixa” | **NO** — completed weighing act (`happened`), not intention |
| “olhei o tanque” | **NO** — completed inspection act |
| “consultei o saldo” | **NO** — completed consultation act |
| “medi a temperatura” | **NO** — completed measurement act |

Principle violated: **correct canonical > safe unresolved >>> wrong canonical** (§5–§6).  
Assigning *Intenção* to past completed observation acts destroys the intention/completed distinction.

### STOP (§10)

```text
EVENT_PARTIAL_FALLBACK_FALSE_CANONICALIZATION
```

**Do not** proceed to Interpreter hardening until partial Event materialization can preserve occurrence semantics **without** assigning `event.intent`.

**Required (future increment, not done here):** represent compositional partial Events as **safe unresolved / non-materialized Event** per ADR 0023 + `ResolutionResult.non_materialized_primitives` — **not** by substituting another arbitrary CORE type.

```text
ONTOLOGY_CHANGE_REQUIRED_FOR_EVENT_FALLBACK = not triggered for this audit
(no new seed proposed; existing keys insufficient for observation acts)
```
